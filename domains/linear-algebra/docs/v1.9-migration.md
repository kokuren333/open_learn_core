# v1.9 Migration

v1.8 Concepts remain the Knowledge Layer. Existing embedded Lessons are preserved as source material while new Course Units become the canonical multi-format teaching units.

| v1.8 | v1.9 |
|---|---|
| Concept | Knowledge Layer Concept |
| embedded Lesson | candidate Learning Unit source |
| Curriculum | Course / Module sequence |
| Exercises | Unit, Module, and cumulative exercise layers |
| Visual Specification | Unit visual placement |
| `_working/` artifacts | `working/` under the Domain |

The initial slice follows `linear-combination → span → linear-independence → basis → dimension → coordinates`. It is intentionally separate from the broader 8-module inventory so that a coherent learning path can be audited before every planned Unit is authored.
