# V2.0 baseline audit

Baseline source: `e6c63d6fd6c112c1b0ebbd60da3e1a129beaac1d` (v1.9).

Before V2.0 authoring, the repository had 8 Modules and 52 Learning Units. The existing test suite passed (33 tests), domain validation passed, and the v1.9 Course Auditor passed. Six vector-space Units were authored; the remaining Units were structurally valid but `planned`, had no exercises, and were not complete learner lessons. There was one module-level exercise set and one cumulative review. HTML and video pilot source paths existed, while a full-course PDF and publication manifest were not yet produced. The legacy concept publish gate was concept-centric and `npm run build -- linear-algebra` selected the wrong argument because the package script prepended `all`.

V2.0 work addresses those concrete gaps with course-level completeness checks, 52 authored Units, 8 Module exercise sets, 5 milestone reviews, full-course web/PDF/video indexes, publication metadata, and offline packaging.

## Reproducible commands

```text
npm install
npm test
npm run validate:all
npm run course:audit -- linear-algebra
npm run build -- linear-algebra
npm run build:pdf -- linear-algebra
npm run build:video -- linear-algebra
npm run publish:manifest -- linear-algebra
npm run publication:audit -- linear-algebra
```
