# MVP v1.9 Design

v1.9 makes the Learning Unit the canonical source for multiple formats while preserving Concepts as concise Knowledge Layer references.

```text
Evidence → Course → Module → Learning Unit → Content Blocks
                                      ├─ HTML
                                      ├─ PDF source / PDF
                                      └─ Video source → Biim adapter → TTS
```

The Course sequence is explicit and is never inferred by traversing the Knowledge Graph. Unit sources keep canonical subtitle text in `script` and pronunciation-oriented text in `spoken_script`. HTML uses `script`; TTS adapters use `spoken_script`.

BiimSlideMaker is a first-party repository and is treated as the reference implementation for the Marp + YAML authoring protocol. Open Learn does not copy its generated media; the adapter writes ignored compatibility files and keeps the canonical source tracked.

PDF uses a Pandoc → LaTeX → LuaLaTeX pipeline when those local tools are installed. The repository always produces inspectable Markdown sources and reports missing external tools clearly.
