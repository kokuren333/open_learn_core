# Lesson Architecture v1.8

Conceptは知識グラフの単位、Lessonは学習の単位です。basisの標準的な流れは次の6単位です。

1. なぜ基底が必要か — R²の問題、材料不足、冗長性、直観
2. Spanと線形独立 — 二つの前提、対比、近い反例
3. 基底の形式的定義 — exact definition、条件A/B、再適用
4. 基底かどうかを判定する — R²/R³の手順とworked reasoning
5. 基底による座標表示 — 基底依存性、変換、行列接続
6. 基底と次元 — 本数、R²/R³、次の線形代数概念

Lesson sectionsは`problem`、`motivation`、`recall`、`intuition`、`definition`、`explanation`、`example`、`counterexample`、`worked_example`、`checkpoint`、`misconception`、`connection`、`summary`、`visual`を用途に応じて組み合わせます。各Lessonに少なくとも一つのcheckpointを置き、Visualは該当する問いの直後に配置します。
